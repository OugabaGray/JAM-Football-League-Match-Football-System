# Module guide

| Module | Purpose |
| --- | --- |
| `league` | League and club models |
| `personnel` | Players, coaches and match officials |
| `fixtures` | Match scheduling and results |
| `sales` | Ticket sales |
| `persistence` | Loading and saving records |
| `reports` | League, match and sales reports |

Each module has a folder under `include/` for headers and a matching folder under `src/` for implementation files. `src/main.cpp` is the entry point.
